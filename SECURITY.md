# Security policy

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/zoispag/provider-sftpgo/security/advisories/new)
rather than in a public issue.

Vulnerabilities in SFTPGo itself or in the Terraform provider belong upstream:
[drakkan/sftpgo](https://github.com/drakkan/sftpgo/security) and
[drakkan/terraform-provider-sftpgo](https://github.com/drakkan/terraform-provider-sftpgo).
